# parkinsons_desease_progression_problem
# Прогнозирование прогрессирования болезни Паркинсона на основе данных белков и пептидов

## Автор: Ангелова Анастасия

## Постановка задачи

Цель проекта — разработать модель для прогнозирования прогрессирования болезни Паркинсона, измеряемого по шкале **MDS-UPDRS**, с использованием данных по уровням белков и пептидов, полученных методом масс-спектрометрии.

Прогнозирование этих показателей важно для:

- понимания динамики заболевания,
- ранней диагностики,
- оптимизации лечебных вмешательств.

---

## Формат входных и выходных данных

### Входные данные:

- `train_peptides.csv`: данные масс-спектрометрии на уровне пептидов.
  - Поля: `visit_id`, `visit_month`, `patient_id`, `UniProt`, `Peptide`, `PeptideAbundance` 

  В данной имплементации эти данные не используются, так как не показали эффективности при отборе признаков

- `train_proteins.csv`: агрегированные данные по белкам.
  - Поля: `visit_id`, `visit_month`, `patient_id`, `UniProt`, `NPX`
- `train_clinical_data.csv` и `supplemental_clinical_data.csv`: клинические данные.
  - Содержат оценки по шкале **MDS-UPDRS (части 1–4)** и информацию о приёме медикаментов.

### Выходные данные:

Таблица с предсказанными значениями шкалы MDS-UPDRS для каждого визита пациента.  
Предсказания делаются для:

- текущего визита,
- горизонтов в **6, 12 и 24 месяца** вперёд.

Каждая запись включает:

- идентификатор пациента (`patient_id`),
- месяц визита (`visit_month`),
- предсказанное значение клинической оценки (`updrs_1–4`).

---

## Метрики

Для оценки качества модели используется **симметричная средняя абсолютная процентная ошибка (SMAPE)**  
С модификацией: `+1` в знаменателе, чтобы корректно обрабатывать случаи, когда прогноз и факт равны нулю.

SMAPE подходит, так как:

- учитывает относительные ошибки,
- адекватен при разных масштабах значений.

---

## Валидация

Для оценки качества модели используется подход, исключающий утечку данных между обучающей и тестовой выборками.  
Разделение данных проводится **по пациентам**, чтобы не использовать данные одного и того же пациента в обучении и тестировании одновременно.

## Моделирование

### Бейзлайн

Модель линейной регрессии с единственным признаком — `visit_month`.

- Отдельная модель для каждого из `updrs_1`, `updrs_2`, `updrs_3`, `updrs_4`
- Минимальный базовый уровень прогноза
- Источник: [baseline kernel](https://www.kaggle.com/code/renataghisloti/simple-linearregression-updated-56-6-smape)


### Основная модель

Ансамблевое решение:

#### LightGBM
- Прогнозы постобрабатываются для минимизации SMAPE
- Признаки:
  - месяц визита, горизонт прогноза,
  - наличие данных крови,
  - клинические признаки,
  - количество предыдущих визитов

#### Нейронная сеть (PyTorch)
- Архитектура: несколько скрытых слоёв, Leaky ReLU
- Оптимизатор: Adam
- Scheduler: косинусный

#### Bagging
- Повышает стабильность и точность предсказаний

Обсуждение решения: [форум Kaggle](https://www.kaggle.com/competitions/amp-parkinsons-disease-progression-prediction/discussion/411505)
